四、使用规范

币面图使用时保持深空蓝底或纯黑底，不加额外投影/描边。
最小尺寸：完整币面 ≥ 96px；仅符号（⚡ 或 QLX）≥ 24px。
多尺寸导出：1024 / 512 / 256 / 128 / 64 全套 PNG + favicon.ico。
不得拉伸变形、不得改金色、不得把 ⚡ 单独放进"闪电币"式文案中。
合规红线：对外统一称 QLX 凭证 / QLX 权益，不称"币"（白皮书 §16、TOKEN.md §1.1）。
