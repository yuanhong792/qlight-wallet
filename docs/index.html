下载与上手

两台电脑连同一 Wi-Fi，各自打开钱包，即自动组网。

🍎 macOS

下载 .dmg → 拖入「应用程序」→ 打开。
首次打开若提示「无法验证开发者」：右键 → 打开（未做公证的普通提示，仅一次）。

🪟 Windows 10 / 11

下载 .zip → 解压 → 双击 qlight-wallet.exe（三个文件须同目录）。
SmartScreen 弹窗：更多信息 → 仍要运行；防火墙询问联网时选允许。

✨ 三步体验联邦转账

  1. 组网：两台设备（或同一台电脑开两个钱包）连同一网络，左上角出现「🌐 联邦 · 2 节点」即成功；
  2. 转账：收款方在「收款」页复制 ql1 开头地址，付款方在「转账」页粘贴并输入金额；
  3. 到账：约 2 秒入块，双方「活动」页自动刷新——付款方、收款方完整地址与时间直接可见。
