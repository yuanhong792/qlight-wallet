QLight Wallet · Windows 绿色版 · v{VERSION}
============================================

【运行】
双击 qlight-wallet.exe 即可。
三个文件（exe + WebView2Loader.dll + libunwind.dll）必须在同一个文件夹，缺一不可。

【系统要求】
- Windows 10 / 11（64 位）
- WebView2 运行时：Win10/11 一般自带；若启动提示缺少 WebView2，
  安装常青版：https://developer.microsoft.com/microsoft-edge/webview2/

【首次运行提示】
- 没有数字签名：SmartScreen 可能弹「已保护你的电脑」，
  点「更多信息」→「仍要运行」即可。
- 首次启动 Windows 防火墙可能询问是否允许联网——选「允许」（联邦网络需要）。

【数据在哪】
C:\Users\<你>\AppData\Roaming\net.qlight.wallet\
（ledger.json 账本 / blocks.jsonl 审计日志 / entities.jsonl 世界实体账本 / 加密密钥库）

【两台电脑组网（联邦）】
同一局域网内：一台 Mac + 一台 Windows（或两台 Windows）各自打开钱包，
mDNS 会自动发现对方，界面左上角出现「🌐 联邦 · N 节点」即组网成功。
同一台电脑开两个实例也可以：第二个实例自动切到 node-1 数据目录。

【转账演示】
收款页复制 ql1 开头地址 → 对方钱包「转账」粘贴 → 输金额 → 签发。
约 2 秒内出块入账，双方活动页自动刷新（无需手动点）。
转账手续费 0.001 QLX（只有转账收费；建造世界不收费）。

【建造与挖矿】
「🌍 世界」页就是编辑器：俯视图点一格，或「进入世界」用第一人称走进去——
右键落下方块、左键拆掉自己签的方块、低头对准脚下连点就是原地起柱。
建造永久免费：签名即落账，不付币、不等确认；防刷只是块高窗口配额（每 1024 块最多 4096 条）。
想拿币就去世界里挖矿：点「⛏ 挖本回合矿脉」，程序在本回合矿脉里挑一格、落一个签名方块，
并提交一张发行凭据；下一个块收下凭据才按 reward_at(h)×50 发行新币，两次发行至少隔 50 块。
没挖到矿的块零发行——币是挖出来的，不是计时器印的（总量仍受 2.1 亿硬顶约束）。

【重要：块格式 v1】
本版起发行规则改变，产出的块为 v1（哈希域 QL-BLOCK-V2）。
组网演示请两端都用本版：更早版本的钱包在首个 v1 块之后会与本节点分叉。

QLX 是演示用「凭证/权益」账本，非投资品。
ML-DSA-65（FIPS 204）抗量子签名，密钥库 AES-GCM + Argon2 加密落盘。
