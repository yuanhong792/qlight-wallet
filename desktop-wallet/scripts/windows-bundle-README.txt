QLight Wallet · Windows 绿色版 · v{VERSION}
============================================

【运行】
双击 qlight-wallet.exe 即可。
三个文件（exe + WebView2Loader.dll + libunwind.dll）必须在同一个文件夹，缺一不可。

【系统要求】
- Windows 10 / 11（64 位）
- WebView2 运行时：Win10/11 一般自带；若启动提示缺少 WebView2，
  安装常青版：https://developer.microsoft.com/microsoft-edge/webview2/

【首次运行提示】
- 没有数字签名：SmartScreen 可能弹「已保护你的电脑」，
  点「更多信息」→「仍要运行」即可。
- 首次启动 Windows 防火墙可能询问是否允许联网——选「允许」（联邦网络需要）。

【数据在哪】
C:\Users\<你>\AppData\Roaming\net.qlight.wallet\
（ledger.json 账本 / blocks.jsonl 审计日志 / entities.jsonl 世界实体账本 / 加密密钥库）

【两台电脑组网（联邦）】
同一局域网内：一台 Mac + 一台 Windows（或两台 Windows）各自打开钱包，
mDNS 会自动发现对方，界面左上角出现「🌐 联邦 · N 节点」即组网成功。
同一台电脑开两个实例也可以：第二个实例自动切到 node-1 数据目录。

【两台电脑互相转币】
收款页复制 ql1 开头地址 → 对方钱包「转账」粘贴 → 输金额 → 签发。
约 2-4 秒内出块入账（节拍 2 秒，组网时一轮还要过 2 秒开票窗口；四进程真链实测块间隔中位 4.0 秒），
双方活动页自动刷新（无需手动点）。
转账手续费 0.001 QLX（只有转账收费；建造世界不收费）。

【建造与挖矿】
「🌍 世界」页就是编辑器：俯视图点一格，或「进入世界」用第一人称走进去——
右键落下方块、左键拆掉自己签的方块、低头对准脚下连点就是原地起柱。
建造永久免费：签名即落账，不付币、不等确认；防刷只是块高窗口配额（每 1024 块最多 4096 条）。
想拿币就去世界里挖矿：点「⛏ 挖本回合矿脉」，程序在本回合矿脉里挑一格、落一个签名方块，
并提交一张发行凭据；下一个块收下凭据才按 reward_at(h)×50 发行新币，两次发行至少隔 50 块。
没挖到矿的块零发行——币是挖出来的，不是计时器印的（总量仍受 2.1 亿硬顶约束）。

【重要：块格式分段到 v6】
激活线是分段的，一条新链从创世跑起也是分段的：块高 ≤200 产 v4，>200 产 v5（光尘与池子进块、由共识结算），>2000 才产 v6（哈希域 QL-BLOCK-V7）。同机四进程真链实测（DESIGN §9.34）：新链前 89 块全是 v4、块行里 `ticket_vrf_hex` 为空——所以「刚装好就产出 v6」是错的，v6 是这条链跑到 2000 之后的事。
v6 的内容：出块人的门票进了块哈希、门票原件随块存放，任何节点都能独立复验"这个块是该出块的人出的"；块时间戳同时成了判据（晚于最近 11 块的中位数、不超前本机时钟 120 秒）。
组网请两端都用本版：更早版本的钱包会在首个 v5 / v6 块之后与本节点分叉——这一次不再静默，界面左上角的网络条会报「规则分歧」。

【跨公网：无头中继节点】
比特币没有"服务器"，但有一堆 24 小时开着的机器。本包同样是这个思路：
  qlight-wallet.exe --node > node.log 2>&1
（GUI 版没有控制台，中继的日志要重定向到文件才有。）
中继只验账、转发、补记录，**不出块、不持币**——币仍然归各台钱包自己签的门票。
默认监听固定端口 tcp/47410（被占用会自动退回随机端口，那样别人就拨不到固定地址）。
环境变量：QL_DATA_DIR 数据目录（默认 ~/.qlight/node）、QL_LISTEN_PORT 端口、
QL_SEEDS 种子地址、QL_ADVERTISE 对外可拨地址（公网机器必填，程序猜不出自己的公网 IP）。
种子地址长这样：/ip4/<IP>/tcp/47410/p2p/<PeerId>，PeerId 就抄节点写在 peer-id.txt 里那一行；
填进自己数据目录的 seeds.json（字符串数组）即可。本版**不自带任何公网种子地址**：
目前还没有一台对外常驻的节点，写进包里就是假话。跨真实公网（NAT/防火墙）尚未实测过一次。

QLX 是密码学研究用途的「凭证/权益」账本，非投资品：账本、签名、出块都是真的在跑；
v6 起出块门票进了块哈希、接收侧逐块复验，块时间戳也成了判据。仍然没做到的是公网对抗的强度：
一个钱包就是一张票（没有质押、没有罚没），而且以上判据只在同机测试里跑过，跨公网一次没实测——这不等于拜占庭容错。
ML-DSA-65（FIPS 204）抗量子签名，密钥库 AES-GCM + Argon2 加密落盘。
